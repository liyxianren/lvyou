# Day5（6 月 15 日）库尔德宁 -> 那拉提方向 -> 独库中北段 -> 奎屯

## 当前结论

Day5 跟随新的库尔德宁 Plan A 调整：早上从库尔德宁镇或景区附近住宿出发，经那拉提镇方向补给后上独库中北段，走乔尔玛、哈希勒根达坂、独山子，晚上住奎屯。

从库尔德宁出发会比那拉提出发多约 2 小时，但换来 Day4 不赶夜路、完整完成库尔德宁 3 小时骑马。Day5 的目标是公路和安全抵达奎屯，不进那拉提景区，不再叠加大景区。

Plan B 保留原那拉提出发逻辑：如果 Day4 启用那拉提自驾并住那拉提镇，Day5 就从那拉提镇直接进独库。

## Plan A 时间线

| 时间 | 安排 | 细节 |
| --- | --- | --- |
| 08:00-08:30 | 库尔德宁早餐 / 退房 / 查路况 | 住宿早餐或打包；确认独库通车、天气、油量和导航。 |
| 08:30-11:00 | 库尔德宁 -> 那拉提镇方向 | 这段是为接独库补路程，少停；路况差就更早出发。 |
| 11:00-11:40 | 那拉提镇补给 / 加油 | 只补给不进景区；买水、咖啡、路餐，确认下一段路况。 |
| 11:40-13:50 | 那拉提方向 -> 乔尔玛 | 进入独库中北段节奏，只在安全观景点短停。 |
| 13:50-14:40 | 乔尔玛午餐 + 烈士陵园 | 简餐或自备路餐；纪念碑短停，不拖太久。 |
| 14:40-18:20 | 乔尔玛 -> 哈希勒根达坂 -> 独山子 | 当天精华：达坂、雪线、防雪长廊、峡谷路段。 |
| 18:20-18:50 | 独库起点 / 独山子短停 | 只做短停，不强制进独山子大峡谷。 |
| 18:50-19:30 | 独山子 -> 奎屯住宿 | 晚上明确住奎屯，不住乔尔玛，也不优先住独山子。 |
| 20:00-21:30 | 奎屯晚餐 / 补给 | 大盘鸡、小公鸡、烧烤、椒麻鸡都可；不喝酒。 |

## 执行规则

- 08:30 前离开库尔德宁最稳；晚于 10:00 离开，就取消独山子大峡谷和所有加项。
- 那拉提镇只是补给点，不进那拉提景区。
- 独库通车状态以当天官方和交警信息为准，不能靠预测硬闯。
- 山路只停观景台或宽阔安全处，不停弯道、落石区、桥面和应急车道。
- 天气变差、起雾、下雨或路况管控时，减少停车，优先安全到奎屯。

## 独库通车核对

出发前必须查：

- 平安独库
- 新疆交警
- 平安独山子
- 当天百度/高德导航路况

6 月 15 日卡在独库开通节点附近，通车与否取决于清雪、落石、天气和交管公告。

## 住宿

晚上住奎屯。

主方案：奎屯明宇丽呈酒店（奎屯站店），目标 220-300 元。  
备选：奎屯独库公路云居酒店 / 天北新区云居酒店，220-280 元可订。  
备用：汉庭 / 如家商旅等奎屯连锁，只看停车、热水和价格。

不住乔尔玛：条件不稳定，Day6 回乌鲁木齐不顺。  
不优先住独山子：独山子离奎屯很近，奎屯吃饭、住宿、补给和第二天上高速更方便。

## 餐食

早餐：库尔德宁住宿早餐或外带，不绕路。  
午餐：那拉提镇快餐或乔尔玛简餐，自备路餐兜底。  
晚餐：奎屯正常吃一顿，大盘鸡、小公鸡、烧烤、椒麻鸡都可。
