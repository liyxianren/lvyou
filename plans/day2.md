# Day2（6 月 12 日）精河县 -> 赛里木湖 -> 苏莱曼烤肉 -> 霍城客之家民宿

## 核心结论

Day2 不再拆其他单独节点。执行方案改成：

精河县木塔商旅驿站 -> 赛里木湖新东门/游客中心 -> 赛里木湖南门 -> 苏莱曼烤肉店(芦草沟店) -> 霍城客之家民宿。

这一天的重点是赛里木湖本身。南门出湖后只做吃饭和入住，不再临时加观景台、补拍点或第二家餐厅。

| 22:00-00:10 | 南门 -> 苏莱曼烤肉 -> 霍城客之家民宿 | 使用用户给定百度路线；吃完直接入住，不再加点。 |

## 赛里木湖打法

不再做全点位清单。保留重点：

- 月亮湾：第一眼湖景短停。
- 三台小岛 / 三台古驿站：近水停靠。
- 松树头：短版俯瞰，不深爬。
- 十里长堤 / 亲水滩 / S 弯 / 灯塔只选一个补拍。

如果停车拥堵或时间被压缩，直接跳过低优先级点，把好光线留给湖边和南门出湖前。

## 晚餐和住宿

晚餐：苏莱曼烤肉店(芦草沟店)。  
住宿：霍城客之家民宿。

执行规则：

- 22:00 左右从赛里木湖南门出湖。
- 出湖后按整条百度导航走，不再加果子沟或其他点。
- 22:20 后才出湖，晚餐压缩到 40 分钟内。
- 苏莱曼烤肉如果关门，直接路餐或民宿附近兜底。
- 出湖前联系民宿，确认可 00:00 前后入住和停车。
