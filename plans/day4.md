# Day4（6 月 14 日）琼库什台徒步 + 后山骑马 -> 特克斯

## 当前结论

Day4 是琼库什台完整游玩日，不再保留其他方案。路线是：

琼库什台村内住宿 -> 乌孙古道入口段徒步 -> 村内午饭休息 -> 后山 3 小时骑马 -> 村落慢走 -> 晚上下山到特克斯县城住宿。

这一天的核心是把琼库什台玩完整，而不是把它当成路过点。晚上必须下到特克斯，为 Day5 早起接乔尔玛和独库北段做准备。

## 百度路程复核

| 路段 | 百度时间 / 距离 |
| --- | --- |
| 琼库什台村落 -> 特克斯县 | 2 小时 16 分钟 / 88.1km |
| 特克斯县 -> 琼库什台村落 | 2 小时 25 分钟 / 90.1km |

Day4 白天基本不动车，只有晚上从琼库什台下山到特克斯。山路夜间驾驶要保守，天气不好就提前出发。

## 乌孙古道入口段规则

- 只走入口段，不做乌孙古道穿越。
- 目标是河谷、木桥、云杉、草甸和轻徒步体验。
- 3 小时是上限，天气不好或路泥就缩到 1.5-2 小时。
- 不涉水，不走不明岔路，不为了照片进入危险河岸。

## 后山骑马规则

- 只做 3 小时后山线。
- 问清价格、路线、是否有人牵马、是否包含拍照停留。
- 新手要求慢骑，不跑马，不边骑边拿手机。
- 雨天、大雾、马队说不清路线或临时加价，就缩短或取消。

## 晚上下山规则

19:10 下山是平衡点。想更稳就 19:00 前离开；如果坚持玩满 12 小时，到特克斯会接近 22:00。

下列情况提前到 18:30 左右下山：

- 下雨或起雾。
- 驾驶员疲劳。
- 马队结束晚于 16:00。
- 村内停车、取行李、晚饭拖延。

## 特克斯住宿要求

特克斯住宿优先级：

1. 停车方便。
2. 热水稳定。
3. 早上退房快。
4. 附近能买早餐/咖啡/水。
5. 能保证 22:00 左右到店。

## 待补

- 特克斯具体住宿。
- 琼库什台后山 3 小时马队联系人和价格。
- 村内午餐/晚餐可执行店或民宿餐。
