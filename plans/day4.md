# Day4（6 月 14 日）Plan A 库尔德宁三小时雪山骑马 / Plan B 那拉提自驾

## 当前结论

Day4 主线切到库尔德宁。Plan A 不是“自驾把库尔德宁所有点刷满”，而是从巩留早进景区，用自驾完成喀峰大本营、齐梦德、云杉林等关键点位，下午把核心时间给官方马队 3 小时雪山骑马线，晚上住库尔德宁镇或景区附近。

那拉提自驾保留为 Plan B：只有放弃库尔德宁并且那拉提自驾票顺利时，才从伊宁出发去那拉提，晚上住那拉提镇。

## 骑马路线口径

小红书目前更一致的结论是：库尔德宁值得为骑马来，单纯自驾会觉得体验一般。3 小时线适合这趟行程，因为它能覆盖云杉林、溪流、草坡和雪山视角，同时不会把 Day5 独库前的体力耗空。

优先级：

1. 云杉之门 / 柏睿营地下方官方马队 3 小时雪山线。
2. 齐梦德官方马队 3 小时云杉林/观景线。
3. 如果官方线排队太久、天气变差、护具/保险不清，取消骑马，只保齐梦德和喀峰大本营。

不做：

- 野骑、黑马队、路线说不清的马队。
- 新手升级 5 小时雪线。
- 边骑边拿手机拍照。
- 为了“雪山更近”走不明路况或无保障线路。

## 小红书参考

- 《库尔德宁骑马攻略｜雪山云杉间驰骋太治愈》：齐梦德停车场/观景台不是同一个点；官方马队有多条线，3 小时雪山/森林线更适合普通游客。
- 《库尔德宁+自驾+骑马，略成功》：中沟进东沟出，自驾送到点位，骑马才是核心体验；野骑安全和规则不如官方队。
- 《库尔德宁马队骑行攻略》：齐梦德线 3 小时往返，夏季按小时计费口径约 80 元/小时，建议问清实际路线和停留时间。
- 《在库尔德宁！我骑马就足够了！》：云杉之门/柏睿营地下方上马点更接近雪山线，3 小时能穿云杉、过溪流、到雪山视角。
- 《库尔德宁正确打开方式，一定要上午早点到！》：上午早进景区，齐梦德停车更稳；中午后停车和人流压力上升。

## 住宿

Plan A 晚上住库尔德宁镇或景区附近。

优先级：

- 镇上民宿/酒店：停车、热水、早餐、晚餐更稳定。
- 景区正规营地：氛围好，但必须确认热水、卫生间、供餐、停车和天气。
- 巩留回住：只作兜底，价格或条件不合适时可用，但会让 Day5 更长。

不建议骑完马再赶那拉提。Day5 本来就是独库长路日，Day4 晚上应恢复体力。

## Plan B：那拉提自驾

启用条件：放弃库尔德宁主线，且那拉提自驾票、住宿和入口规则都顺利。

Plan B 路线：

伊宁住宿点 -> 那拉提游客中心/票务核验 -> 空中草原/游牧人家 -> 盘龙谷道 -> 河谷草原轻扫 -> 那拉提镇住宿。

Plan B 执行规则：

- Day3 必须住伊宁，不去巩留。
- 抢不到自驾票时，不把区间车作为默认替代。
- 午后先抓空中草原/游牧人家，前几站不耗太久。
- 河谷草原靠近住宿，只做傍晚轻扫。
- 晚上住那拉提镇，Day5 从那拉提出发上独库。

## 待补

- 库尔德宁住宿具体候选：先看镇上停车热水稳定酒店，再看景区营地。
- 3 小时马队现场确认：价格、护具、保险、是否马夫牵马、是否能到雪山视角。
