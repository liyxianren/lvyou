# Day3（6 月 13 日）霍城 -> 伊宁六星街 -> 琼库什台

## 当前结论

Day3 不去晃晃村。早上在霍城客之家民宿吃早餐、拍民宿自带薰衣草，10:00 直接去伊宁。伊宁只保留六星街午餐、轻逛和补给，补给在六星街顺手完成，出城前到中国石油加油站(伊宁市天山站)加油，然后进琼库什台。

路线是：

霍城客之家民宿 -> 六星街景区-地下停车场 -> 中国石油加油站(伊宁市天山站) -> 特克斯琼库什台雪山古道民宿。

今天的核心是傍晚前后进琼库什台。伊宁不是深度 citywalk；中午热，六星街 1-1.5 小时足够。晚饭优先雪山古道民宿留餐，不再进村后开车找店。

## 途经点

1. 霍城客之家民宿：早餐、拍自带薰衣草、退房。
2. 六星街景区-地下停车场：停车后午餐、轻逛、买水和路餐。
3. 中国石油加油站(伊宁市天山站)：出城前加油、厕所、整理车内。
4. 特克斯琼库什台雪山古道民宿：停车、晚饭、确认 Day4 马队。

## 执行规则

- 民宿有自己的薰衣草，不再去晃晃村。
- 伊宁只保留六星街，不去喀赞其、伊犁河和汉人街。
- 六星街补给顺手买，不单独拉出 40 分钟；小红书反馈琼库什台整体是景区价，进村前不要空手。
- 14:20 前后离开伊宁最舒服，15:00 是最晚上限。
- Day3 住宿已落到特克斯琼库什台雪山古道民宿，不再泛泛找“村内民宿”；用它作为 Day4 后山卡口、区间车备用和正规马队的执行前哨。

## 雪山古道民宿执行重点

住宿名称：特克斯琼库什台雪山古道民宿。

地址：喀拉达拉镇琼库什台哈依河片区70号附1号。

地图短链：https://j.map.baidu.com/6c/5q6k

执行确认：

1. 提前离线保存百度短链定位，山里信号差时直接按离线点走。
2. 到店先问车停哪里、行李怎么搬、热水供应时段。
3. 确认晚餐和早餐能否在民宿解决；晚饭优先民宿留餐，不能解决就让老板推荐最近村内吃饭点。
4. 请民宿帮忙联系正规马队，问清 Day4 后山卡口停车场能否自驾抵达；如果被拦，村委会/2号停车场哪个是官方区间车上车点；再确认骑马路线、价格、出发时间和是否有人牵马。
5. 确认林溪餐厅、松塔烤肉、拾叁台餐厅是否营业。Day4 晚饭优先林溪，想吃烤肉/野蘑菇火锅就换松塔。
6. 19:00-20:00 到店是否可接受；如果山路慢或天气差，提前电话说明。

## 待补

- 雪山古道民宿电话 / 订单号 / 停车说明。
- 晚餐、早餐是否在民宿解决；晚餐菜单优先热菜、汤和主食。
- 后山卡口停车场自驾放行口径、区间车上车点、正规马队价格、联系人和当天允许路线。
- 林溪餐厅、松塔烤肉、拾叁台餐厅的营业时间和具体导航名。
- 伊宁午餐按实际停车位置再选。
