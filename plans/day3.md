# Day3（6 月 13 日）霍城 -> 晃晃村 -> 伊宁补给 -> 琼库什台

## 当前结论

Day3 已确定为琼库什台进村日。路线是：

霍城客之家民宿 -> 晃晃村薰衣草轻停 -> 伊宁市午餐、加油和补给 -> 琼库什台村落住宿。

今天的核心不是伊宁深玩，而是安全、准时地进入琼库什台。伊宁只承担午餐、加油和路餐补给。14:00 左右必须离开伊宁，避免后半段山路太晚。

## 百度路程复核

| 路段 | 百度时间 / 距离 |
| --- | --- |
| 霍城客之家民宿 -> 晃晃村 | 16 分钟 / 11.0km |
| 晃晃村 -> 伊宁市 | 1 小时 19 分钟 / 80.5km |
| 伊宁市 -> 琼库什台村落 | 4 小时 22 分钟 / 216.5km |

Day3 纯开车约 5 小时 57 分钟，实际按 6-6.5 小时体感预留。

| 20:00-21:30 | 村里轻走 / 早休息 | 只在住宿附近轻走，不开车找夜景。准备 Day4 徒步和骑马装备。 |

## 执行规则

- 晃晃村只看薰衣草，不加果子沟、松树头或其他绕路点。
- 伊宁不是完整 citywalk；13:10 后优先补给和加油。
- 14:30 还没离开伊宁，就取消一切额外逛街，直接去琼库什台。
- 琼库什台住宿选村里，不选后山；村里停车、晚饭、早餐和马队联系都更稳。
- 晚上到村后不要再开车找机位，Day4 才是正式游玩日。

## 住宿要求

琼库什台村里住宿优先级：

1. 能停车。
2. 有独卫和稳定热水。
3. 能提供晚餐和早餐。
4. 能帮忙联系正规马队。
5. 到店时间 18:30-20:00 可接受。

## 待补

- 琼库什台具体住宿候选。
- 后山马队价格和联系人。
- 伊宁午餐和补给点按实际停车位置再补。
