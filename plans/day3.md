# Day3（6 月 13 日）客之家 -> 晃晃村薰衣草 -> 果子沟观景台 -> 清水河午饭 -> 伊宁住宿

## 核心结论

Day3 不去那拉提，住伊宁。路线按“霍城客之家民宿 -> 晃晃村 -> 果子沟观景台-地上停车场 -> 霍城县清水河镇 -> 伊犁老城文化旅游区/喀赞其 -> 六星街景区 -> 伊宁住宿点”执行，进伊宁后用住宿导航链接 https://j.map.baidu.com/c8/pjHi 精确到店。

晃晃村这次定位为薰衣草轻停，不再写成泛泛找别的花。小红书近期实况集中在薰衣草，百度地图能搜到“晃晃村”和“晃晃村薰衣草花河”，但后者路况、收费和花况争议大；普通车只安排村口、上进路、音乐广场附近或好停车农户薰衣草田，30-40 分钟足够。

果子沟观景台不必人人爬山。百度地图能识别“果子沟观景台-地上停车场”，这是当天路线点。基础版在正规停车场、观景台和栈道入口看桥，30-45 分钟；登高版才按 90-110 分钟预留，包含走栈道/上坡、高位拍全桥、下撤。云龙栖大酒店、第三个停车场、高位机位出片，但停车和收费不稳定，只作为现场加分项，不写成硬任务。

伊宁段按“停车优先、喀赞其短走、六星街傍晚”的顺序。住宿如果在六星街/喀赞其外圈且停车可靠，先入住再步行；如果在主干道或开发区，先外围停车逛完，再 19:00 后到店。Day4 要从伊宁去那拉提，住宿优先停车、早退房和出城效率。

## 小红书参考

- 《5.22晃晃村薰衣草花海实况》《📍新疆霍城芦草沟晃晃村薰衣草》：晃晃村近期主线是薰衣草，5 月底开始有花，6 月更稳；农户田间小路可能按 5-10 元/人收拍照费。
- 《霍城晃晃村，薰衣草河谷劝退！》《晃晃村真不用去河谷，村口免费的不香吗》：薰衣草河谷和后山路况、收费、花况争议明显，普通车不硬进。
- 《果子沟大桥的玩法》：南门出来可导航果子沟观景台，沿线多个观景台；高位视野更好，但骑马、导游和停车都需要现场判断。
- 《果子沟大桥一路上的观景平台都去了！》《果子沟大桥只需去这一个地方全部锁定》：云龙栖大酒店附近高位出片，官方观景台/地上停车场更稳；酒店停车位和收费不稳定。
- 《2026新规，自驾来六星街的宝子提前码住！》《伊宁 六星街生态停车场 房车友好》：旅游旺季六星街核心区域有通行管制，外围停车和生态地上停车场更适合自驾。
- 《伊宁💙六星街Citywalk半日打卡攻略》《伊宁｜六星街+喀赞其，我更喜欢前者》：喀赞其适合短看蓝墙和生活感但晒、休息点少；六星街更适合 17:00 后甜品、咖啡、彩色门窗和休息。
- 《伊犁清水河镇饭好吃推荐系列，三家店》《新疆清水河镇探店—楼兰兄弟秘烤》：清水河镇适合承担午饭，快餐和本地小馆比拖到伊宁更稳。

## 百度地图核对

- “晃晃村”：百度地图显示位于新疆维吾尔自治区伊犁哈萨克自治州霍城县芦草沟镇四宫村三组。
- “果子沟观景台-地上停车场”：百度地图显示在霍城县果子沟牧场 G312（沪霍线），比只搜“果子沟大桥”更适合作为停车节点。
- “伊犁老城文化旅游区”：百度地图显示为 4A 景区，游客服务中心和地上停车场可作为喀赞其入口定位。
- “六星街景区”：百度地图显示在伊宁市工人街一带；“六星街景区-生态地上停车场”可作为自驾停车备选。

## 执行规则

- 晃晃村只看薰衣草，按 30-40 分钟轻停；花况一般、收费不清、土路难走就缩到 15-20 分钟。
- 果子沟不必爬山；基础版 30-45 分钟，登高版 90-110 分钟。风大、雾重、停车乱、体力不足就只走基础版。
- 果子沟只能在合法观景台或安全停车点停留，不能桥面、弯道、应急车道停车。
- 清水河镇小店在百度地图上可能不稳定，路线用“霍城县清水河镇”作午饭节点，到镇上再搜具体店名。
- 喀赞其导航用“伊犁老城文化旅游区”，不要只搜“喀赞其”。
- 六星街核心街区不自驾进入，车停外围停车场或酒店后步行。
- 伊宁住宿优先停车可靠、能早退房、Day4 去那拉提出城不绕；睡前确认 Day4 导航、那拉提入园方式、早餐、加油和天气。
