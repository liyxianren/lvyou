# Day3（6 月 13 日）Plan A 伊宁半日后住巩留 / Plan B 原果子沟进伊宁

## 当前结论

Day3 已切为库尔德宁前置日。Plan A 不再爬松树头/果子沟，不住伊宁/特克斯；路线是：

霍城客之家民宿 -> 晃晃村薰衣草轻停 -> 伊宁午餐/喀赞其或六星街短逛 -> 洗衣/补给/加油 -> 巩留县城住宿。

这样 Day4 早上可以从巩留进库尔德宁，避免从伊宁或特克斯长距离硬赶。原“晃晃村 + 松树头/果子沟 + 清水河午饭 + 伊宁住宿”降为 Plan B，仅在放弃库尔德宁、改回那拉提时使用。

## Plan A 执行规则

- 晃晃村只看薰衣草，普通车不进路况不明的花河、后山土路。
- 伊宁只做半日，不做完整 Citywalk；核心是吃饭、短逛、洗衣、补给、加油。
- 16:30 后还没开始补给，就砍掉六星街或慢晚餐。
- 17:30 后还没离开伊宁，直接去巩留。
- 巩留住宿必须确认停车和热水；Day4 要早进库尔德宁。

## Plan B：原果子沟进伊宁线

启用条件：放弃库尔德宁主线，改回 Day4 那拉提自驾。

Plan B 路线：

霍城客之家 -> 晃晃村 -> 松树头-地上停车场 -> 果子沟观景台-地上停车场 -> 霍城县清水河镇午饭 -> 伊犁老城文化旅游区/喀赞其 -> 伊宁住宿。

Plan B 要点：

- 松树头半山腰湖景平台保底，桥景方向看体力和天气。
- 12:20 还没接近桥景高点就下撤，13:25 必须离开松树头。
- 果子沟观景台只在合法停车点短停，不桥面/弯道/应急车道停车。
- 清水河镇吃午饭，下午进伊宁短走，晚上住伊宁。
- 它不适合 Day4 库尔德宁，因为会让第二天早上从伊宁硬赶。

## 待补

- 伊宁午餐和洗衣点：按实际酒店/停车位置再补，不为了网红店绕路。
