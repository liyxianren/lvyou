# Day3（6 月 13 日）霍城客之家民宿 -> 伊宁 -> 那拉提草原

## 核心结论

Day3 从霍城客之家民宿出发，不回头追赛湖日出。伊宁只做午餐、补给和短停，下午推进到那拉提草原住宿。

## 时间线

| 时间 | 安排 | 细节 |
| --- | --- | --- |
| 08:40-09:20 | 霍城客之家民宿早餐 / 退房 | 不为早餐绕路，补水、咖啡和路餐优先。 |
| 09:20-12:10 | 前往伊宁 | 按当天导航进伊宁，进城后优先停车。 |
| 12:10-13:30 | 伊宁午餐 / 补给 | 过油肉拌面、烤包子、酸奶，补水和咖啡。 |
| 13:30-14:30 | 伊宁短停 | 只做轻量城市停留，不把伊宁拉成长线。 |
| 14:30-18:40 | 前往那拉提草原住宿 | 下午必须推进到那拉提，不再加远点。 |
| 18:40-20:30 | 入住 / 晚餐 / 整理 | 先停车入住，再吃饭，确认 Day4 入园和早餐。 |

## 执行规则

- Day2 如果到民宿很晚，Day3 上午不追赶，保证驾驶状态。
- 伊宁只作为午餐和补给点。
- 下午不再临时加远点，优先顺利到那拉提。
- 睡前确认 Day4 那拉提入园、加油、早餐和天气。
