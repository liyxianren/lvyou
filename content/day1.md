# Day1｜6 月 11 日｜乌鲁木齐落地 → 安集海大峡谷 → 奎屯

> 版本定位：**安集海确定执行版**  
> 出行人员：2 人，男生主驾 + 女朋友  
> 车辆：影豹 2023 款混动，机场送车，最高保险 / 免赔方案  
> 当天角色：安集海是主景点，奎屯只负责住宿、晚餐、补给、休息。  
> 本版更新：因租车为机场送车，且已购买最高保险 / 免赔，取车交接按 10–15 分钟处理，把节省出来的 30–40 分钟留给安集海。

## 1. 核心结论

Day1 不再按“落地适应 + 安集海可去可不去”来排，而是明确改成：

**乌鲁木齐落地 → 机场快速交接取车 → 北京路 / 汇嘉时代方向午餐 → 尽早离开乌鲁木齐 → 直接前往安集海大峡谷 → 傍晚深度停留 2.5–3 小时 → 晚上到奎屯天北新区住宿。**

这一天不进乌鲁木齐老城区，不排队吃网红店，不在奎屯安排游玩。奎屯本身不是 Day1 的看点，只作为第二天去赛里木湖前的功能性落脚点。

### 当天执行重点

1. **机场取车要快而不漏项**：车辆送到机场，最高保险 / 免赔已买，交接按 10–15 分钟处理；仍需拍一圈车况视频并确认油量、还车规则和救援电话。
2. **节省时间留给安集海**：不要把取车节省出的时间用于午餐排队或乌鲁木齐逛街，全部顺延给安集海停留。
3. **午餐要控时**：第一顿新疆菜可以吃，但只点一轮，目标 45–55 分钟结束。
4. **安集海是主景点**：建议停留 2.5–3 小时，重点看峡谷、傍晚光线和拍照。
5. **奎屯只负责休整**：晚到奎屯可以接受，不需要给奎屯预留游玩时间。
6. **安全边界明确**：只走公共道路、主路、硬化路或明显可通行道路；不进入封闭区、矿区路、河谷底、危险土坡或私自管理区域。

## 6. 安集海大峡谷游玩细节

### 6.1 定位

安集海是 Day1 核心景点，但它不能按完整成熟景区来处理。本计划按以下方式执行：

```text
外围可通行区域观景 + 短距离步行 + 傍晚光线拍照
```

不做以下行为：

- 不进封闭区；
- 不下谷底；
- 不走矿区支路；
- 不开进松软土坡；
- 不贴近崖边；
- 不和管理人员争论；
- 不为了拍车照把车开到危险位置。

### 6.2 停车原则

到达后先观察 2–3 分钟，再决定停车位置。

优先选择：

- 路面平整；
- 地面压实；
- 不挡路；
- 可以掉头；
- 离峡谷边足够远；
- 周围有其他正常车辆停靠痕迹。

避免选择：

- 土坡边缘；
- 车辙很深的路；
- 石子松散处；
- 突出平台边缘；
- 河谷下方；
- 矿区或施工道路；
- 无法掉头的窄路尽头。

### 6.3 拍照节奏

| 时间段 | 拍摄内容 | 说明 |
|---|---|---|
| 18:20–18:40 | 找点 + 第一轮全景 | 先看环境，不急着拍人像。 |
| 18:40–19:40 | 主观景 + 人像 | 女生换外套、帽子、墨镜；男生先确认车和撤离路线。 |
| 19:40–20:50 | 傍晚光线 | 拍峡谷层次、侧光、人和峡谷远景。 |
| 20:50–21:20 | 收尾 + 二次构图 | 拍最后一组远景，收拾东西，检查车内物品，正式出发去奎屯。 |

### 6.4 安全边界

人离崖边至少 **5 米以上**。如果地面松软、风大、视线差，距离继续拉大。

拍照时不建议：

- 背对峡谷倒退；
- 跳跃拍照；
- 站在突出平台；
- 为了构图靠近裂缝边缘；
- 让女朋友一个人站到远处边缘；
- 为了拍视频边走边退。

订前确认：

- 是否免费停车；

### 12.1 出机场前

### 12.2 机场送车交接时

本次是送车到机场，并且购买最高保险 / 免赔，交接目标控制在 **10–15 分钟**。不做过度验车，但必须留下基础证据。

快速拍视频：

- [ ] 前脸；
- [ ] 后杠；
- [ ] 左右车身；
- [ ] 四个轮毂；
- [ ] 前后挡风玻璃；
- [ ] 内饰；
- [ ] 油表；
- [ ] 里程；
- [ ] 行驶证 / 保险信息。

快速确认：

- [ ] 最高保险 / 免赔是否已经生效；
- [ ] 是否覆盖轮胎、玻璃、底盘；
- [ ] 非铺装路、封闭路、矿区路是否免责；
- [ ] 油量规则：满油取还，还是按当前油量还；
- [ ] 还车地点和还车时间；
- [ ] 违章押金周期；
- [ ] 道路救援电话。

交接原则：

```text
不抠小划痕，但必须拍视频；
不和送车人员长聊，但必须问清保险和还车；
不把省下来的时间花在机场或午餐，直接留给安集海。
```

### 12.3 从乌鲁木齐出发前

- [ ] 确认油量；若非满油且后续高速前顺路，再补油；

### 12.4 到安集海前

- [ ] 不要等油量低再找加油站；
- [ ] 看到服务区可以补厕所；
- [ ] 后半段导航如果出现土路，先停车判断；
- [ ] 不要跟着陌生车乱进岔路；
