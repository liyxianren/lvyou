# Day1 补充说明｜乌鲁木齐机场 -> 新天润 -> 安集海/巴音沟 -> 精河县

这一天以“快速落地进入自驾节奏”为核心。网页主卡片和时间线是执行依据：

- 总路线：乌鲁木齐机场取车 -> 大掌柜芦花鸡·大盘鸡 -> 安集海大峡谷 -> 巴音沟 -> 精河县木塔商旅驿站
- 午餐：大掌柜芦花鸡·大盘鸡新疆菜(新天润店)
- 采购：新天润同街区超市完成，只买路上刚需
- 住宿：精河县木塔商旅驿站

## 总路线导航

Day1 页面顶部的“Day1 一键总路线”是当天主导航。百度地图起点和终点之间只放 3 个途经点：大掌柜芦花鸡·大盘鸡新疆菜(新天润店)、安集海大峡谷、巴音沟，低于 5 个途经点上限。

晚饭不进入导航路线。到木塔商旅驿站后先入住，再在住处旁边找拌面、抓饭、丸子汤、烧烤或简单热食。

## 执行重点

机场取车后直接去新天润，不进乌鲁木齐老城区。午餐和采购合并在一个街区处理，目标是 14:30 前离开新天润。

这顿可以吃正式新疆菜，但不要把它做成慢节奏城市饭局：如果上菜慢，就减少菜品或打包；如果 14:25 还没完成采购，只买水、咖啡、馕、湿巾后立刻走。

## 采购原则

新天润只做 Day1-Day2 路上刚需补给：

- 水、咖啡或功能饮料
- 馕、面包、烤包子等耐放主食
- 酸奶、水果、巧克力或能量棒
- 纸巾、湿巾、垃圾袋
- 充电线、充电宝只做确认，不在现场慢慢挑

不要买需要冷藏很久、汤汤水水、味道很重或吃起来复杂的东西。

## 安集海规则

安集海和巴音沟按同一峡谷区域处理，只做安全观景短停，不进入封闭区域、矿区路、河谷底、危险土坡或明显非铺装烂路。现场如果有围挡、劝返、风沙、降雨或路况不清，直接跳过巴音沟并撤离去精河县。

## 到精河县后

先入住木塔商旅驿站，再就近吃饭。晚餐以拌面、抓饭、丸子汤、烧烤或简单热食为主，不再跨城找店。

睡前确认 Day2 去赛里木湖的油量、水、咖啡、路餐、相机/手机充电和离线地图。
