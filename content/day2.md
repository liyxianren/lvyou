# Day2 补充说明｜精河县 -> 赛里木湖 -> 苏莱曼烤肉 -> 霍城客之家民宿

这一天的主线只保留一个清晰节奏：白天和日落都给赛里木湖，南门出湖后直接走“吃饭 -> 民宿”。

- 路线：精河县木塔商旅驿站 -> 赛里木湖新东门/游客中心 -> 赛里木湖南门 -> 苏莱曼烤肉店(芦草沟店) -> 霍城客之家民宿
- 核心：赛里木湖停留到日落后
- 出湖：22:00 左右从南门离开
- 晚餐：苏莱曼烤肉店(芦草沟店)
- 住宿：霍城客之家民宿

## 执行重点

到赛里木湖后不要再把点位拆成一串硬打卡。当天按光线、停车和体力取舍，重点保留湖面、雪山、公路、近水点和日落。

南门出湖之后不再加果子沟大桥、观景台或补拍点，直接按百度路线走：

赛里木湖南门 -> 苏莱曼烤肉店(芦草沟店) -> 霍城客之家民宿。

## 晚到规则

- 出湖前联系霍城客之家民宿，确认可 00:00 前后入住。
- 22:20 后才出湖，晚餐压缩到 40 分钟内。
- 苏莱曼烤肉如果关门，直接路餐或民宿附近兜底，不再绕第二家。
- 人疲劳时优先安全到民宿，晚餐可以打包或跳过。
