# Day4 攻略｜Plan A 库尔德宁三小时雪山骑马 / Plan B 那拉提自驾

Day4 主线改成库尔德宁。今天不追求自驾刷点，核心体验是从云杉之门/柏睿营地下方或齐梦德官方马队走 3 小时雪山骑马线：穿云杉林、溪流和草坡，到雪山视角后返回。晚上住库尔德宁镇或景区附近，不赶去那拉提。

- Plan A：巩留 -> 库尔德宁中沟 -> 喀峰大本营 -> 齐梦德/云杉之门 -> 3 小时雪山骑马 -> 库尔德宁住宿
- Plan B：伊宁 -> 那拉提游客中心 -> 空中草原/游牧人家 -> 盘龙谷道 -> 那拉提镇住宿
- 当前按 Plan A 执行，Plan B 只有放弃库尔德宁时使用

## Plan A：怎么玩库尔德宁

早上从巩留出发，尽量 10:00 前进入库尔德宁。小红书共识是上午早点到更顺，齐梦德停车点中午后容易困难。景区按现场指引中沟进、东沟出；自驾只负责把人送到喀峰大本营、齐梦德、云杉之门这些点，不要把每个路边点都刷满。

上午先走十里画廊、蜂香驿站、喀峰大本营。看到溪流、云杉、雪山同框的安全停车点再停。喀峰大本营附近适合拍雪山草坡和小屋。

中午前后到齐梦德停车点/云杉林。这里可以拍海蒂和爷爷小木屋、云杉林、草坡和观景台方向。当天如果要骑 3 小时雪山线，齐梦德徒步不要走满 3 小时，只做 60-90 分钟。

下午核心是 3 小时雪山骑马线。优先云杉之门/柏睿营地下方官方马队；如果现场不能走，就退到齐梦德官方马队 3 小时线。只选正规/官方马队，确认路线、价格、护具、保险、是否马夫牵马。不找野骑或黑马队，不升级 5 小时线。

## 住宿和收尾

骑马后不再赶去那拉提镇。沿东沟方向看溪水和云杉短停后，直接入住库尔德宁镇或景区附近。住宿必须确认停车、热水、早餐和晚餐；景区营地有氛围但条件波动大，价格虚高或热水不稳就住镇上。

## Plan B：那拉提自驾

Plan B 保留原那拉提方案：Day3 住伊宁，Day4 从伊宁去那拉提，抓空中草原、游牧人家和盘龙谷道，晚上住那拉提镇。它只在放弃库尔德宁主线并且那拉提自驾票顺利时启用。
