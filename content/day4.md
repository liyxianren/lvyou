# Day4 攻略｜琼库什台村内轻走 + 后山卡口骑马 + 村内晚饭 -> 特克斯从前慢民宿

Day4 是琼库什台完整体验日，但不需要 7 点多赶。上午不再把乌孙古道入口当成稳定执行项目，只在民宿周边和村内合法开放区域轻走拍照；下午把核心放到后山卡口。路线优先自驾到百度当前识别的琼库什台村落-新桥2号停车场（后山卡口），被拦再退回村委会/2号停车场坐官方区间车。

- 总路线：雪山古道民宿 -> 民宿周边/村内轻走 -> 琼库什台村落-新桥2号停车场(后山卡口，优先自驾；被拦则区间车) -> 后山网红秋千方向骑马/徒步 -> 林溪餐厅/松塔烤肉 -> 特克斯从前慢民宿(八卦城店)
- 地图按钮：顶部使用一条完整百度路线，串联“民宿 -> 新桥2号停车场/后山卡口 -> 林溪餐厅 -> 从前慢”
- 后山卡口：不是网红秋千，只是车止点；卡口后按当天允许路线徒步或找正规马队
- 区间车备用：小红书 2026 常见口径为 20 元/人单程、约 15-20 分钟、坐满发车
- 林溪餐厅到特克斯县：原基准约 2 小时 23 分钟 / 88.1km；到从前慢民宿以百度实时导航为准
- 住宿：特克斯从前慢民宿(八卦城店)，短链 https://j.map.baidu.com/1b/CKpM

2. 村内轻走：民宿周边、村内道路、草场边轻走拍照，不进封控/不明山区。

6. 下山从前慢：19:40 左右从林溪餐厅/村内停车点离开，按 2.5 小时预留下山，22:10-22:30 入住特克斯从前慢民宿。

## 后山卡口执行规则

后山主路线不是“导航到网红秋千”。正确执行是先到后山卡口停车场，卡口以后再徒步或骑马。能不能自驾到卡口，以当天村里/卡口管理为准。

优先顺序：

1. 先尝试自驾到琼库什台村落-新桥2号停车场（后山卡口）。
2. 如果被拦，退回琼库什台村委会停车场、1号或 2号停车场。
3. 坐官方区间车到后山卡口。
4. 到卡口后，按当天允许路线选择正规马队或短线徒步。

出发前问清：

- 新桥2号停车场/后山卡口当天是否允许社会车辆抵达
- 被拦时从哪个停车场坐区间车，是否 20 元/人单程
- 骑马路线是否到网红秋千、草坡或雪山视角
- 总时长是否包含拍照、休息和上下马整理
- 是否一人一马，是否有人牵马
- 天气不好、卡口不放行、临时加价时能否缩短或取消

## 吃饭路径

Day3 晚上先让雪山古道民宿留饭，所以 Day4 不要为吃饭早起。Day4 午饭只吃轻一点，真正的正餐放到骑马/徒步后。

晚饭优先级：

1. 林溪餐厅：适合骑马后吃正餐。优先点虎皮辣子烧茄子、土豆丝、汤或牛排火锅。
2. 松塔烤肉：适合想吃更有特色的烤肉、野蘑菇火锅和热菜时替换。
3. 拾叁台餐厅：营业且顺路时作为备选。

任何一家排队久、不开门或离车太远，就换下一家；19:40 左右必须准备从林溪餐厅/村内停车点下山。

## 晚上下山规则

19:40 左右下山是这版的平衡点。想更稳就 19:00 前出发；如果后山返回晚、区间车排队、晚饭排队或天气不好，到特克斯会接近 22:30。

遇到下雨、起雾、司机疲劳或天黑后视线差，就不要硬撑，直接减少下午停留，提前下山。
