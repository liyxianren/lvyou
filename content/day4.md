# Day4 攻略｜Plan A 那拉提自驾 / Plan B 夏塔一日

Day4 也保留两套方案。Plan A 是当前主线：抢到那拉提自驾票就从伊宁去那拉提，午后抓空中草原/游牧人家和盘龙谷道。Plan B 是夏塔支线：如果没抢到那拉提自驾票，或判断周末那拉提体验太差，就以前一晚住昭苏/夏塔口为前提，把这一天完整给夏塔。

- Plan A：伊宁住宿点 -> 那拉提游客中心/票务核验 -> 空中草原/游牧人家 -> 正规马队骑马可选 -> 盘龙谷道 -> 河谷草原近住宿轻扫 -> 塞美天山奇缘民宿
- 门票：那拉提自驾票按 200 元/人，两人 400 元预留；抢不到优先切 Plan B 夏塔，不把区间车当默认替代
- 入园：当天开放入口、西门/游客中心换票、车牌核验规则以官方和现场为准，不硬套攻略
- 玩点：前几站短停，重点留给游牧人家溪边草原、雪山草甸和网红桥后方开阔坡线；傍晚走盘龙谷道拍森林、公路弯道和河谷层次
- 骑马：只做正规马队 1 小时轻体验；排队久、保险不清、路线含糊就跳过，不影响主线
- 河谷草原：离塞美天山奇缘民宿近，放到傍晚顺路轻扫；天黑、下雨或疲劳就直接入住
- 住宿：Day4 晚上住塞美天山奇缘民宿，导航 https://j.map.baidu.com/92/wPkh，只住一晚，不去巴音布鲁克
- Day5 衔接：从民宿出发走独库中北段到奎屯，睡前确认独库通车和天气

当天重点：不要把时间平均分给所有站点。午后先抓那拉提最稳的草原雪山画面，傍晚再用盘龙谷道补森林和公路层次；河谷草原靠近住宿，是收尾和兜底，不是白天主线。

## Plan B：夏塔一日骨架

Plan B 不从伊宁当天硬赶夏塔，最好接 Day3 的伊昭公路：前一晚住昭苏县或夏塔景区口，Day4 早上去夏塔旅游景区游客中心。

- 昭苏 -> 夏塔游客中心：百度地图初核约 76.5km / 1小时25分。
- 伊宁 -> 夏塔游客中心：百度地图初核约 270.7km / 4小时22分，只适合作为距离判断，不建议 Day4 早上从伊宁出发再完整游玩夏塔。
- 游玩骨架：夏塔游客中心 -> 区间车进景区 -> 将军桥/鲜花台/雪山谷轻徒步 -> 返回昭苏或夏塔口住宿。
- 还要补的细节：门票和区间车、区间车终点、将军桥到鲜花台步行节奏、是否骑马或电瓶车、具体住宿点、Day5 如何衔接独库。

Plan B 的价值是把一天还给风景和徒步感，不是为了省路程。启用它时，Day4 不再使用那拉提自驾票、那拉提住宿和当前 Day5 那拉提出发逻辑，后续要把住宿和 Day5 路线一起补齐。
