# Day4 备用说明｜那拉提一整天慢玩

Day4 的网页展示以结构化卡片为准，这里保留维护摘要，避免后续改动时把策略改乱。

- 主线：那拉提花栖民宿 -> 票务/车牌核验 -> 空中草原/游牧人家 -> 正规马队骑马 -> 盘龙谷道/河谷草原 -> 那拉提镇晚餐 -> 那拉提花栖民宿
- 门票：那拉提自驾票按 200 元/人，两人 400 元写入固定预算；抢不到才切普通票+区间车兜底
- 入园：提前确认塔亚苏门岗、西门换票、车牌核验规则；现场按官方口径执行
- 玩点：上午保空中草原和游牧人家溪边草原，下午保盘龙谷道；河谷草原做收尾
- 骑马：可安排，但只选正规马队；1 小时轻体验优先，预算 80 元/小时/人起
- 住宿：Day4 晚上继续住那拉提花栖民宿或那拉提镇同级备选，不去巴音布鲁克
- Day5 衔接：从那拉提出发走独库中北段到奎屯，睡前确认独库通车和天气

执行重点：这一天不再为了赶巴音布鲁克而压缩那拉提。那拉提本身值得完整一天慢玩，骑马是加分项，盘龙谷道和游牧人家才是主线。
