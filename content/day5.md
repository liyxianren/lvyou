# Day5 攻略｜特克斯 -> 乔尔玛 -> 独库北段 -> 奎屯/独山子

Day5 是琼库什台方案里最累的一天，但路线成立：前一晚已经从琼库什台下到特克斯，今天从特克斯早起接乔尔玛，再把下午留给独库北段。

- 总路线：特克斯县城住宿 -> 乔尔玛革命烈士陵园 -> 哈希勒根达坂/独库北段 -> 独山子 -> 奎屯
- 纯开车和独库停靠：约 11-12 小时
- 住宿：优先奎屯；如果到独山子太晚或人很累，就住独山子
- 硬约束：07:30 从特克斯出发，13:00 左右进入独库北段

## 时间线

| 时间 | 安排 | 执行要点 |
| --- | --- | --- |
| 07:00-07:30 | 特克斯早餐 / 退房 | 早餐可打包，不为吃饭拖延。 |
| 07:30-12:00 | 特克斯 -> 乔尔玛 | 百度约 4 小时 22 分钟 / 288.8km；这段不加景点。 |
| 12:00-12:40 | 乔尔玛午餐 / 补给 | 简餐、厕所、补水，烈士陵园短停。 |
| 12:40-13:00 | 进入独库北段 | 中午接上独库，避开 19:00 后入口管控风险。 |
| 13:00-18:30 | 乔尔玛 -> 哈希勒根达坂 -> 独山子方向 | 只停安全观景点，不停弯道、桥面、落石区。 |
| 18:30-19:00 | 独山子短停 / 判断住宿 | 状态好就继续到奎屯；太累就住独山子。 |
| 19:00-19:30 | 独山子 -> 奎屯 | 百度约 24 分钟 / 13.2km。 |
| 20:00-21:30 | 晚餐 / 休息 | 酒店附近吃，不喝酒。 |

## 独库执行规则

2026 年独库公路 6 月 1 日恢复通行，乔尔玛至 G217 入口 19:00 后社会车辆不得进入。今天必须中午前后接上乔尔玛，不要拖到傍晚。

不加其他景区，不进独山子大峡谷深玩。遇到天气差、起雾、落石风险或交通管控，减少停车，优先出山和入住。

## 住宿判断

优先住奎屯，吃饭、住宿、补给和 Day6 回乌鲁木齐都更稳。

如果到独山子已经 19:30 后、天气差或驾驶员明显疲劳，直接住独山子，不硬撑到奎屯。
