# Day3 备用说明｜霍城 -> 伊宁老城 -> 那拉提花栖民宿

Day3 的网页展示以结构化卡片为准，这里只保留备用摘要。

- 起点：霍城客之家民宿
- 主线：霍城客之家民宿 -> 伊犁老城文化旅游区/喀赞其 -> 汉人街大巴扎 -> 六星街景区 -> 那拉提花栖民宿
- 住宿：那拉提花栖民宿，百度短链为 https://j.map.baidu.com/ab/_S7i

## 总路线导航

Day3 页面顶部使用一条百度完整路线，包含 3 个伊宁途经点：伊犁老城文化旅游区/喀赞其、汉人街大巴扎、六星街景区，终点为那拉提花栖民宿。

住宿短链解析到百度 POI uid：`eca4af4e9ed4899abca822de`。百度显示那拉提花栖民宿位于那拉提镇那拉提村苗圃街十二巷008号，距离那拉提旅游风景区游客服务中心约 2.9 公里、11 分钟。

## 小红书取舍

- 喀赞其：比六星街更有生活感，适合看蓝墙、老城巷子、居民生活和自然街景。导航用“伊犁老城文化旅游区”，不要只搜“喀赞其”。
- 汉人街大巴扎：适合午餐、补给和本地小吃，不把正餐放在六星街。
- 六星街：更商业化，适合冰淇淋、咖啡、彩色门窗和文创店；下午店铺可能开得不齐，不排队硬刷。
- 那拉提镇：晚上不空白，晚餐固定吃 Anaer阿娜尔家·Kazakh新疆菜；小红书实吃帖把阿娜尔家列为值得一吃，百度地图显示从那拉提花栖民宿过去约 7-8 分钟、1.8 公里。Day3 不强行进景区，Day4 再正式玩那拉提。

执行重点：16:00 左右离开伊宁；如果 16:30 后才离开，晚上只做阿娜尔家晚餐和休息。
