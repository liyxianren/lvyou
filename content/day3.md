# Day3 攻略｜晃晃村薰衣草 -> 果子沟观景台 -> 伊宁住宿

Day3 不赶那拉提，重点是把霍城到伊宁这一段顺路玩明白：早上轻停晃晃村看薰衣草，上午去果子沟观景台，午饭在清水河镇解决，下午进伊宁短走喀赞其，傍晚逛六星街，晚上住伊宁。

- 起点：霍城客之家民宿
- 主线：客之家 -> 晃晃村 -> 果子沟观景台-地上停车场 -> 霍城县清水河镇 -> 伊犁老城文化旅游区/喀赞其 -> 六星街景区 -> 伊宁住宿点
- 住宿：打开已收藏的伊宁住宿导航 https://j.map.baidu.com/c8/pjHi ，以百度地图显示位置为准

## 总路线导航

Day3 的总路线使用百度地图完整串联：霍城客之家民宿 -> 晃晃村 -> 果子沟观景台-地上停车场 -> 霍城县清水河镇 -> 伊犁老城文化旅游区 -> 六星街景区 -> 伊宁住宿。进伊宁后，再按住宿导航链接精确到店。

晃晃村不是泛泛找别的花，这次只看薰衣草。客之家到晃晃村约 12 公里 / 19 分钟，安排 30-40 分钟即可：村口、上进路、音乐广场附近或好停车的农户薰衣草田，薰衣草状态好就拍，收费不清或土路难走就走。

果子沟观景台不等于必须爬山。基础版在正规停车场和观景台/栈道入口看桥，30-45 分钟能完成；想拍全桥、峡谷、云杉和雪山层次，再加走栈道或上坡高位，按 90-110 分钟预留。不要把悬崖石、松树头、无人机机位都塞进来。

## 伊宁怎么玩

伊宁段不求全，按“喀赞其短走 + 六星街傍晚”执行。

- 喀赞其 / 伊犁老城：导航用“伊犁老城文化旅游区”，看蓝墙、木门、街巷和生活感，60 分钟左右足够；晒、休息点少，不坐马车，不做深度家访。
- 六星街：17:00 后更合适，店开得更全，光线更柔。走古兰丹姆冰淇淋、阿谷朵格瓦奇、俄罗斯风情园/娜塔莎的家、竹马西地客、草原商店这一线，排队超过 15 分钟就换店。
- 停车：六星街旅游旺季核心街区可能限行，自驾车停外围停车场或酒店。百度地图可搜“六星街景区-生态地上停车场”作为停车备选。

## 住宿规划

Day3 住伊宁，住宿优先级是停车可靠、能早退房、Day4 去那拉提出城不绕。

- 如果住宿导航显示在六星街/喀赞其步行圈，且酒店确认有停车：15:35 到伊宁后先入住、放行李，再步行或打车去喀赞其和六星街。
- 如果住宿在主干道或开发区：先把车停到老城或六星街外围停车场，完成 Citywalk 后，19:00 后打开住宿导航到店。
- 如果老城核心街区民宿停车不明确，不作为主方案。宁可住主干道带停车酒店，晚上打车去六星街。

当天重点：晃晃村看薰衣草，不追后山；果子沟按体力切短版/登高版；伊宁先解决停车，再慢逛和入住。Day4 早上从伊宁出发去那拉提，晚上不要熬太晚。
