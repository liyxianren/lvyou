# Day3 攻略｜Plan A 伊宁半日后住巩留 / Plan B 果子沟进伊宁

Day3 主线已经切到库尔德宁前置：上午从霍城客之家退房后，只在晃晃村轻停看薰衣草；中午到伊宁吃饭，下午短逛喀赞其/六星街并处理洗衣、加油、路餐补给；傍晚去巩留县城住。原来的松树头/果子沟 + 伊宁住宿降为 Plan B，只在放弃库尔德宁、改回那拉提时启用。

- Plan A：霍城客之家 -> 晃晃村 -> 伊宁午餐/喀赞其/六星街 -> 洗衣补给 -> 巩留县城住宿
- Plan B：霍城客之家 -> 晃晃村 -> 松树头/果子沟 -> 清水河午餐 -> 伊宁住宿
- 住宿：Plan A 住巩留县城；Plan B 住伊宁
- 决策：当前按 Plan A 执行；Plan B 仅作为那拉提备选联动

## Plan A：库尔德宁前置日

晃晃村这次只看薰衣草，30-35 分钟轻停即可。普通车不进薰衣草河谷或后山土路，花况一般、收费不清、停车不顺就缩到 15-20 分钟。

伊宁段只做半日，不做完整 Citywalk。午餐优先停车方便的拌面、抓饭、烤肉或新疆菜；下午喀赞其和六星街二选一，也可以喀赞其 60 分钟后去六星街买冰淇淋/咖啡就走。真正要完成的是洗衣、补水、路餐、加油和 Day4 骑马装备准备。

17:00-18:00 之间离开伊宁去巩留最稳。晚于 18:30 还没离开，就取消六星街或慢晚餐，直接去巩留。巩留住宿优先停车、热水、早餐/洗衣，不为了景观住到偏远位置。

## Plan B：原果子沟进伊宁线

只有放弃库尔德宁主线、改回 Day4 那拉提时，才启用原 Day3。Plan B 才安排松树头/果子沟和伊宁住宿：上午晃晃村后去松树头-地上停车场，半山腰湖景平台保底，体力和天气都顺再加桥景方向；不顺就改果子沟观景台-地上停车场短版。午饭放清水河镇，下午进伊宁短走，晚上住伊宁。

Plan B 的风险是松树头容易吃掉 1-3 小时，会压缩伊宁和休息；它不适合 Day4 库尔德宁早进景区。
