# Day6 攻略｜奎屯丽漫酒店 -> 乌鲁木齐还车 -> 博物馆/大巴扎 -> 机场

Day6 不是一条全程自驾路线。上午自驾从奎屯丽漫酒店回乌鲁木齐机场/机场附近还车点，13:00 完成还车；还车后已经没有车，市区午餐、博物馆、大巴扎和回机场都按打车/步行执行。

- 自驾路线：奎屯丽漫酒店 -> 乌鲁木齐天山国际机场 / 机场附近还车点
- 还车后打车线：还车点/机场 -> 小李子血站大盘鸡（西北路店） -> 新疆维吾尔自治区博物馆 -> 新疆国际大巴扎 -> 天山机场，页面按每一段分别给导航按钮
- 硬约束：13:00 还车，18:00 离开市区，20:50 起飞
- 未确认项：最终还车门店以租车平台为准，确认后替换顶部自驾导航

## 图片攻略页面

Day6 页面使用 `static/day6-route-map-clean.jpg`。图上 1-7 点分别对应早餐退房、高速回乌市、加油还车、西北路午餐、新疆博物馆、大巴扎轻逛和回机场起飞。

顶部有 5 个百度地图按钮：奎屯到还车点、还车点到小李子、小李子到博物馆、博物馆到大巴扎、大巴扎回机场。不要把博物馆和大巴扎塞进自驾导航里，也不要用一个多途经点链接让百度自己解析。

## 时间线

| 时间 | 安排 | 执行要点 |
| --- | --- | --- |
| 08:30-09:00 | 起床、早餐、退房 | 酒店含早就直接吃；不含早就楼下买咖啡、包子或酸奶。9 点必须出发。 |
| 09:00-12:00 | 奎屯丽漫 -> 乌鲁木齐还车区 | 约 3 小时 / 250km；中途只做厕所、咖啡和补水，不安排景点。 |
| 12:00-13:15 | 加油、清车、还车 | 还车前加满油，拍车身、轮毂、油表、里程和内饰视频。 |
| 13:15-14:50 | 打车去西北路午餐 | 还车后打车去小李子血站大盘鸡；排队超过 25 分钟就换附近拌面/新疆菜。 |
| 14:50-16:20 | 新疆博物馆 | 有预约、行李能处理、15:40 前能到才进；不满足就取消。 |
| 16:30-17:50 | 国际大巴扎轻逛 | 只买少量手信和上厕所，不深逛、不排长队。 |
| 18:00-19:00 | 打车回机场 | 遇晚高峰、下雨、行李麻烦或大巴扎拥挤，17:30-17:45 就走。 |
| 19:00-20:50 | 值机安检 + 起飞 | 机场内解决晚餐和水，20:50 飞贵阳。 |

## 执行规则

13:00 还车是上午唯一核心。还车点确认前，先按乌鲁木齐天山国际机场/机场附近还车点规划；如果租车平台给出市区门店，要把 Day6 顶部自驾路线替换成真实门店。

博物馆和大巴扎都服从机场时间。没有预约、行李不方便、午餐拖延或当天太累，就取消博物馆；大巴扎只保留轻逛，不为它赌晚高峰。
