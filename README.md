# 新疆 6 天 5 晚 + 贵阳 1 日旅行执行网站

本项目是一个面向旅途中实时查看、执行和调整行程的网站。核心目标不是单纯展示旅游攻略，而是把每天的路线、住宿、票务、预算、驾驶提醒、风险备选方案和现场执行清单集中在一个移动端友好的页面中，方便两人自驾旅行时随时查看下一步该做什么。

## 当前版本

当前已实现 Flask v1：

- 手机优先的今日看板、Day1 详情、账本、预订与采购、AI 助手页面
- 使用 `data/trip.json` 保存行程、预算、预订、采购和记账数据
- AI 助手接入 DeepSeek OpenAI-compatible API，只生成变更预览，确认后才写入 JSON
- API key 不写入代码，通过 `DEEPSEEK_API_KEY` 环境变量或本地 `.env` 文件配置

## 本地运行

```powershell
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

然后在 `.env` 中填写：

```env
DEEPSEEK_API_KEY=你的 DeepSeek Key
DEEPSEEK_MODEL=deepseek-v4-flash
```

启动服务：

```powershell
python app.py
```

电脑访问：`http://127.0.0.1:5000`  
手机访问：电脑和手机连接同一 Wi-Fi 后，用电脑局域网 IP 访问 `http://电脑IP:5000`

## 产品目标

网站需要服务真实旅途执行，优先解决以下问题：

- 打开首页即可看到“今天行程”和“下一步动作”
- 每天能快速查看路线、驾驶时长、住宿、吃饭、景点、门票和注意事项
- 对酒店、景区预约、还车、加油、身份证检查等关键动作做提醒
- 对独库公路未通车等高风险事项提供备选方案
- 记录预算、实际花费和剩余预算
- 在手机弱网场景下仍能查看核心行程信息

## 每日执行清单

### Day 1：6 月 11 日，乌鲁木齐 -> 奎屯

核心任务：

- 12:30 抵达乌鲁木齐天山机场
- 13:00 办理租车，拍摄全车验车视频，包括轮胎、轮毂、底盘、车顶
- 市区午餐，可选托克逊老四号餐厅或楼兰秘烤
- 超市采购矿泉水、功能饮料、馕、自热食品、零食、水果、湿巾、垃圾袋、手机支架
- 前往奎屯，途中可在石河子服务区休整
- 傍晚前往安集海大峡谷看日落
- 晚餐可选俭寨奎城味到大盘鸡、王飞沙湾大盘鸡

预算参考：约 775 元

### Day 2：6 月 12 日，奎屯 -> 赛里木湖

核心任务：

- 早上在奎屯加满油，注意新疆加油站通常需要身份证
- 中午抵达赛里木湖东门
- 提前通过“赛里木湖景区”公众号实名预约
- 自驾环湖路线：月亮湾 -> 亲水滩 -> 克勒涌珠 -> 点将台 -> S 弯 -> 松树头
- 可选择景区内毡房营地或清水河镇住宿
- 傍晚二次进湖看日落

预算参考：约 860 元

### Day 3：6 月 13 日，赛里木湖 -> 果子沟 -> 伊宁

核心任务：

- 如住景区内，早起看赛里木湖日出
- 南门出发前往果子沟大桥观景台
- 中午前往伊宁
- 午餐可安排过油肉拌面、烤包子、手工冰淇淋
- 下午入住并休整
- 傍晚游览喀赞其民俗村和六星街附近区域
- 晚餐安排伊宁夜市或烤肉

预算参考：约 530 元

### Day 4：6 月 14 日，伊宁 -> 那拉提 -> 巴音布鲁克

核心任务：

- 这是全程驾驶和游玩压力最大的一天之一，早出发
- 伊宁出发前加满油
- 那拉提草原需提前在“智游那拉提”预约
- 游玩重点：空中草原、游牧人家、河谷草原
- 下午穿过独库中段前往巴音布鲁克
- 入住巴音布鲁克镇
- 19:30 前到九曲十八弯观景台占位，等待日落

预算参考：约 1,346 元

### Day 5：6 月 15 日，独库公路北段

核心任务：

- 出发前必须确认独库公路通车状态
- 路线：巴音布鲁克 -> 乔尔玛 -> 独山子 -> 奎屯
- 途中经过哈希勒根达坂，可能遇到积雪和低温
- 乔尔玛烈士陵园停留
- 北行途中根据安全条件在观景台停车拍照
- 抵达独山子大峡谷和独库公路起点
- 晚上返回奎屯住宿

预算参考：约 510 元

备选方案：

如独库北段未通车，执行巴音布鲁克 -> G218 -> 那拉提 -> 新源 -> 独山子 -> 奎屯绕行方案，约 500km / 8h。该方案会增加驾驶压力和成本，需要在网站中作为高优先级风险预案展示。

### Day 6：6 月 16 日，奎屯 -> 乌鲁木齐 -> 贵阳

核心任务：

- 早上从奎屯返回乌鲁木齐
- 可安排国际大巴扎、红山公园等轻量市区游
- 午餐可选领馆巷美食街或小李子血站大盘鸡
- 还车前加满油，并拍摄全方位还车视频
- 预留充足时间前往机场
- 20:00 乌鲁木齐飞贵阳，6 月 17 日 00:15 到达

预算参考：约 390 元

### 贵阳 1 日：6 月 17 日

核心任务：

- 凌晨抵达贵阳后，在机场附近胶囊酒店或钟点房休息
- 早餐：金牌罗记肠旺面
- 上午：黔灵山公园
- 午餐：青云路、护国路或二七路小吃街
- 下午：甲秀楼、电台街 Citywalk
- 晚餐：青云路夜市
- 19:30 前往机场
- 21:50 贵阳飞深圳

预算参考：约 250 元

## 关键风险与提醒

### 独库公路通车状态

独库公路是本计划中最关键的不确定因素。当前行程时间为 6 月 11 日至 6 月 16 日，Day 5 计划行驶独库公路北段，时间卡在每年通车节点附近。

网站需要在行前和旅途中突出提醒：

- 出发前一周关注“平安独库”公众号
- 必要时拨打 12328 交通运输服务监督电话确认
- 如未通车，切换到 Day 5 绕行方案

### 加油与证件

- 新疆加油站通常需要身份证和人脸识别
- 副驾可能需要下车等待
- 建议每天出发前加满油
- Day 4、Day 5 路线长，加油站间距大，需要重点提醒

### 驾驶安全

- Day 4 和 Day 5 驾驶时间长，需保证睡眠
- 山区和独库路段不抢时间，不疲劳驾驶
- 每 1.5-2 小时停车休息
- 遇到积雪、落石、施工、限行，优先保守处理

### 离线能力

- 出发前下载新疆全境离线地图
- 网站核心行程信息应支持离线查看
- 重要酒店、景区、机场、租车点信息应提前缓存或截图

### 衣物与装备

- 墨镜、帽子、防晒霜必备
- 独库达坂可能低温或遇雪，准备冲锋衣或薄羽绒服
- 车内常备水、干粮、垃圾袋、湿巾、充电线、手机支架

## 网站 MVP 功能

第一版网站建议优先完成以下功能：

1. 首页今日看板
   - 当前日期对应行程
   - 下一站、下一件事、预计出发时间
   - 今日驾驶距离、驾驶时长、住宿地点
   - 今日预算和重点风险

2. 行程日历
   - Day 1 到 Day 6 + 贵阳 1 日
   - 每天的时间线、地点、餐饮、住宿、门票、费用
   - 支持快速切换日期

3. 地点与导航
   - 每个地点记录名称、类型、城市、备注
   - 预留导航链接字段
   - 酒店、景区、机场、餐厅分组展示

4. 预订与核查清单
   - 酒店是否已订
   - 景区票是否已预约
   - 租车、还车、加油、证件检查
   - 独库通车状态核查

5. 预算追踪
   - 展示预算项、预计金额、实际金额
   - 自动计算剩余预算
   - 标记超支项和可节省项

6. 应急与备选方案
   - Day 5 独库未通车绕行方案
   - 重要电话和备用操作
   - 低油量、弱网、晚到、景区关闭等场景提示

## 项目定位

这个项目最终应当是一个“旅途执行中控台”：

- 出发前，用它检查票务、酒店、路线和预算
- 旅途中，用它判断下一站、下一笔花费、下一项提醒
- 出现变化时，用它快速切换备选路线
- 旅行结束后，用它复盘实际花费和体验

第一版不需要做成复杂平台，先把这次新疆和贵阳行程跑顺。只要手机打开后能在 10 秒内回答“现在该去哪、要花多少钱、有没有坑”，它就是成功的。
